# Документация к проекту "Priority Queue"

## 🎯 Общее описание

**Priority Queue** — реализация очереди с приоритетами на основе бинарной кучи.  
Структура поддерживает два режима работы:
- **max-heap** (по умолчанию) — извлекает наибольший элемент,
- **min-heap** — извлекает наименьший элемент.

### Основные функции:
- Добавление элемента с сохранением свойств кучи
- Извлечение элемента с наивысшим приоритетом
- Безопасная работа с пустой очередью
- Поддержка копирования, перемещения и сравнения

## 🧪 Тестирование

Проект включает **21 юнит-тест**:
- конструкторы и операторы присваивания
- Работу в режимах max-heap и min-heap
- Обработку исключений при работе с пустой очередью
- Граничные случаи: `INT_MAX`, `INT_MIN`, один элемент
- Корректность операторов `==`, `!=` и `<<`
- Поведение при копировании и перемещении

## 🛠️ Сборка и запуск

### Требования:
- C++11 или выше
- GoogleTest 
- CMake 3.10+

### Сборка:
```bash
mkdir build
cd build
cmake ..
make
```

### Запуск тестов:
```bash
./lab1_tests
```

## 🔧 Особенности реализации

### Внутренняя структура:
- Хранение данных в `std::vector<int>`
- Поддержание свойств кучи через функции `sift_up()` и `sift_down()`
- Универсальная функция сравнения `compare(a, b)` для обоих режимов
